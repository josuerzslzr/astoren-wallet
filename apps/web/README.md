# web

Vite 8 + React 19 + React Router 8 + TanStack Query 5 + Tailwind 4 + shadcn/ui (`components.json`) + lucide-react. Generated with `create-vite` (react-ts) and `shadcn init`.

- `pnpm --filter web dev`: dev server
- `pnpm --filter web build`: type-check and production build
- `pnpm --filter web test`: Vitest (jsdom)
- `pnpm --filter web lint`: root `eslint.config.js`

Story 1.1 ships a single placeholder route. Screens, design tokens and navigation land in Story 1.7.
